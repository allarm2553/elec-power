คู่มือการใช้งานและจัดการเรียนรู้อิเล็กทรอนิกส์กำลัง

คู่มือฉบับสมบูรณ์ครอบคลุมทั้งขั้นตอนสำหรับครูผู้สอนในการตั้งค่า Google Sheets และระบบป้องกันการส่งงานซ้ำแยกรายหน่วย (Anti-Duplicate Submission) ตลอดจนคู่มือการทดลอง การวัดรูปคลื่น และการส่งรายงานชิ้นงานสำหรับนักศึกษา

ข้อมูลหลักสูตรและการเปิดระบบใช้งาน (Quick Start)

ระบบห้องปฏิบัติการวิศวกรรมอิเล็กทรอนิกส์กำลังเสมือนจริง (Power Electronics Web Learning Lab) ออกแบบตามเกณฑ์มาตรฐานหลักสูตรระดับ ประกาศนียบัตรวิชาชีพชั้นสูง (ปวส.) รหัสวิชา 30105-2019 โดยจำลองฟิสิกส์ การควบคุมสวิตชิ่ง และการวัดสัญญาณทางไฟฟ้าผ่านเทคโนโลยี HTML5 Canvas 2D Vector แบบ 60 FPS

1
ตรวจสอบความพร้อมของระบบ (System Requirements)
ติดตั้ง Node.js (v14.0 ขึ้นไป) และใช้งานผ่านเบราว์เซอร์มาตรฐาน เช่น Google Chrome, Microsoft Edge, Mozilla Firefox หรือ Safari บนคอมพิวเตอร์ แท็บเล็ต หรือสมาร์ตโฟน
2
คำสั่งเปิดรันเซิร์ฟเวอร์ Localhost
เปิดโปรแกรม Terminal หรือ Command Prompt เข้าไปยังโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง: 
cd /path/to/Elec_Power
node server.js
3
การเข้าใช้งานผ่าน Web Browser
เปิดเบราว์เซอร์แล้วเข้าสู่หน้าหลักที่: http://localhost:8082/
คำแนะนำการใช้งาน: หากใช้งานบนอุปกรณ์แท็บเล็ตหรือสมาร์ตโฟน แนะนำให้หมุนหน้าจอเป็นแนวนอน (Landscape Mode) เพื่อให้การแสดงผลออสซิลโลสโคป กราฟ และผังวงจรมีความกว้างเต็มประสิทธิภาพ
คู่มือการจัดการสำหรับครูผู้สอน (Instructor Workflow)

ครูผู้สอนสามารถรวบรวมคะแนนและผลการทดลองของนักศึกษาทุกคนเข้าสู่ Google Sheets ของตนเองแบบเรียลไทม์ โดยใช้สคริปต์ Code.gs ที่แนบมากับระบบ

ขั้นตอนการสร้างและติดตั้ง Google Apps Script (Code.gs)

1
สร้าง Google Sheet ใหม่
สร้างชีตใหม่บน Google Drive ของครูผู้สอน เช่น ตั้งชื่อ คะแนนวิชาอิเล็กทรอนิกส์กำลัง_2569
2
เปิดหน้าเขียนสคริปต์ (Apps Script)
ไปที่เมนู ส่วนขยาย (Extensions) > คลิก Apps Script ลบโค้ดเดิมออกทั้งหมด
3
นำโค้ดในไฟล์ Code.gs มาวาง (เลือกลิงก์เดียว หรือ แยกหน่วย)
• แบบลิงก์เดียวจบ (แนะนำ): ใช้โค้ดจาก Master_Code.gs วางใน Google Sheet ไฟล์เดียว จะจัดการแยกชีตให้อัตโนมัติ 7 แท็บ (Unit 1 - 7)
• แบบแยกแต่ละหน่วย: คัดลอกโค้ดจากไฟล์ Unit1/Code.gs ถึง Unit7/Code.gs นำไปวางในชีตของแต่ละหน่วยแยกกัน 7 ไฟล์
จากนั้นกดปุ่ม Save (บันทึก)
4
ทำให้ใช้งานได้เป็นเว็บแอป (Deploy as Web App)
กดปุ่มสีน้ำเงิน Deploy (การทำให้ใช้งานได้) > เลือก New deployment (รายการใหม่) > เลือกประเภทเป็น Web app:
• Execute as (ดำเนินการในฐานะ): Me (ฉัน / เจ้าของชีต)
• Who has access (ผู้มีสิทธิ์เข้าถึง): Anyone (ทุกคน) *(จำเป็นต้องเลือก Anyone เพื่อให้นักเรียนส่งคะแนนได้)*
กดปุ่ม Deploy และคัดลอก URL ที่ลงท้ายด้วย /exec
ข้อสำคัญ: สิทธิ์การเข้าถึง (Who has access) ต้องเลือกเป็น "Anyone" (ทุกคน) เสมอ หากเลือก "Only myself" หรือกำหนดเฉพาะองค์กร นักศึกษาจะไม่สามารถส่งผลการทดลองเข้ามาได้

การบันทึก URL กลางและการแชร์ลิงก์ 1-Click (?gas=)

5
บันทึก URL กลางผ่าน Master Portal
เปิดหน้าหลัก Master Dashboard > คลิกปุ่ม "สำหรับครูผู้สอน" ด้านบนขวา > วาง Web App URL ในช่องแล้วกด "บันทึก URL กลาง" ระบบจะเชื่อมต่อไปยังทุกหน่วยทันที
6
แชร์ลิงก์ให้นักเรียน (?gas=)
ในตารางด้านล่างของหน้าต่างครูผู้สอน กดปุ่ม "📋 คัดลอกลิงก์ให้นักเรียน" ในหน่วยที่ต้องการสอน ลิงก์จะแนบพารามิเตอร์ ?gas=... อัตโนมัติ เช่น:
https://<username>.github.io/Elec_Power/Unit1/?gas=https://script.google.com/macros/s/AKfycb.../exec
เมื่อนักศึกษาเปิดลิงก์นี้ เครื่องของนักศึกษาจะผูกกับชีตของครูทันทีโดยที่ นักศึกษาไม่ต้องกรอก URL เอง

ระบบป้องกันการส่งงานซ้ำแยกรายหน่วย (Anti-Duplicate Submission)

ระบบใช้การตรวจสอบ 2 ชั้น (Two-Layer Isolation):
1. ระดับ Client: จัดเก็บประวัติรหัสที่เคยส่งแยกตามรายหน่วย (submitted_student_ids_unit1 ถึง unit7) หากพิมพ์รหัสเดิมจะขึ้นเตือนสีแดงและล็อกปุ่มส่งทันที
2. ระดับ Server (Code.gs): ฟังก์ชัน checkDuplicate() ตรวจสอบคอลัมน์ C (รหัสนักศึกษา) ก่อนบันทึกข้อมูล ป้องกันการส่งซ้ำ
3. การล้างแคชส่งซ้ำ: ครูสามารถกดปุ่ม "ล้างประวัติส่งซ้ำ" ในหน้าต่างครูผู้สอนเฉพาะหน่วยนั้น หรือกดปุ่ม Master Reset ในหน้าหลักเพื่อล้างประวัติทุกหน่วยพร้อมกัน

คู่มือการปฏิบัติงานสำหรับนักศึกษา (Student Guide)
1
การเข้าสู่ห้องปฏิบัติการ
เปิดลิงก์ที่ได้รับจากครูผู้สอน (ซึ่งแนบ ?gas= มาด้วย) หรือเปิดหน้า Master Portal แล้วเลือกหน่วยการเรียนรู้ที่ครูมอบหมาย
2
การศึกษาทฤษฎีและปรับแต่งพารามิเตอร์
ศึกษาเนื้อหาตามลำดับแท็บ ใช้สไลเดอร์และปุ่มควบคุมในการเปลี่ยนค่า เช่น แรงดัน, กระแส, ความถี่, มุมจุดชนวน α, หรือดิวตี้ไซเคิล พร้อมสังเกตการเคลื่อนที่ของประจุและรูปคลื่นไฟฟ้าบนออสซิลโลสโคป
3
การบันทึกผลการทดลอง (Data Logger)
เมื่อปรับสภาวะการทำงานตามใบงาน ให้กดปุ่ม "💾 บันทึกค่าลงใน Data Logger" ข้อมูลจะถูกบันทึกลงในตารางด้านล่าง สามารถกดปุ่ม "Export CSV" เพื่อดาวน์โหลดข้อมูลเป็นไฟล์สเปรดชีต
4
การทำแบบทดสอบท้ายหน่วย (Quiz Evaluation)
ไปยังแท็บ แบบทดสอบ (Quiz) อ่านคำถามและเลือกคำตอบให้ครบทุกข้อ ระบบจะแสดงผลคะแนนและเฉลยละเอียดโดยอัตโนมัติ
5
การกรอกข้อมูลและส่งผลการทดลองเข้าสู่ระบบครู
เลื่อนไปยังส่วนกรอกข้อมูลผู้ทำการทดลอง:
  • กรอก ชื่อ-นามสกุล ผู้เรียน
  • กรอก รหัสประจำตัวนักศึกษา (เช่น 66301050012)
  • กรอก กลุ่มเรียน/แผนกวิชา (เช่น ปวส.2 ชอ.2)
หากรหัสนักศึกษาถูกต้องและยังไม่เคยส่งงานในหน่วยนี้ ปุ่ม "ส่งข้อมูลเข้า Google Sheets" จะพร้อมใช้งาน กดส่งแล้วรอจนขึ้นเครื่องหมายถูกสีเขียว "✓ ส่งข้อมูลสำเร็จเรียบร้อย!"
การส่งรายงาน PDF: นักศึกษาสามารถกดปุ่ม "พิมพ์รายงาน PDF" เพื่อสั่งพิมพ์หรือบันทึกหน้าจอรายงานผลพร้อมคะแนนสอบและตารางแล็บเป็นไฟล์ PDF ส่งให้อาจารย์เป็นหลักฐานได้ทันที

คำถามที่พบบ่อยและการแก้ไขปัญหา (Troubleshooting & FAQ)
Q1: กดส่งผลการทดลองแล้วขึ้นแจ้งเตือน "กรุณาระบุ Web App URL"?
วิธีแก้: สำหรับนักศึกษาให้เปิดผ่านลิงก์ที่อาจารย์ส่งให้ซึ่งจะมี ?gas=... แนบมาด้วย หรือหากเปิดด้วยตนเอง ให้กดปุ่ม "สำหรับครูผู้สอน" ด้านบน แล้วนำ Web App URL ของอาจารย์มาบันทึกในระบบก่อนส่ง
Q2: ข้อมูลไม่เข้า Google Sheet หรือขึ้น Network Error?
วิธีแก้: ปัญหานี้มักเกิดจากตอน Deploy บน Google Apps Script ไม่ได้ตั้งค่าสิทธิ์เข้าถึง (Who has access) ให้เป็น "Anyone" (ทุกคน) ให้ครูผู้สอนเข้าไปที่ Apps Script > กด Manage deployments > แก้ไขการตั้งค่า Who has access เป็น Anyone แล้วกด Deploy อีกครั้ง
Q3: ขึ้นเตือนสีแดงว่า "รหัสนี้เคยส่งงานแล้ว (ห้ามส่งซ้ำ)" แต่ต้องการส่งใหม่?
วิธีแก้: ระบบ Anti-Duplicate ป้องกันการส่งซ้ำเพื่อความโปร่งใส หากครูต้องการให้นักเรียนส่งใหม่หรือครูต้องการทดสอบระบบ ให้เปิดหน้าต่าง "สำหรับครูผู้สอน" ในหน่วยนั้น แล้วกดปุ่ม "🔄 ล้างประวัติส่งซ้ำ (หน่วยที่ X)" หรือกดปุ่ม "ล้างประวัติส่งซ้ำ (Anti-Cheat Cache)" ในหน้าหลัก
Q4: ส่งคะแนนหน่วยที่ 1 ไปแล้ว จะถูกบล็อกไม่ให้ส่งหน่วยที่ 2 หรือไม่?
คำตอบ: ไม่ถูกบล็อกอย่างแน่นอน ระบบแยกกุญแจจัดเก็บข้อมูลอย่างอิสระในแต่ละหน่วย (submitted_student_ids_unit1 ถึง unit7) นักศึกษาสามารถทำแบบทดสอบและส่งผลงานได้ครบทุกหน่วยโดยไม่มีการบล็อกข้ามหน่วย
